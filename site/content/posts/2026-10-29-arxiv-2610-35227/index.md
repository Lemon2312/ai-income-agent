量子コンピュータを大きくしようとすると、意外なところで壁にぶつかります。それは「配線」です。量子ビット（量子コンピュータの計算の単位）を1つ動かすのに何本もの線が要り、その線を通して冷凍機の中に熱まで入りこんでしまうのです。

今回の論文は、ラジオやテレビの電波と同じ「周波数で分ける」発想で、1本の線に複数の命令をまとめて流すしくみを提案しました。さらに実験で、1本の線から4つの量子ゲート（量子ビットへの操作）を同時に動かしても、誤りが増えないことを確かめています。

{{< tanerisu >}}「線を減らす」ってどういうことか、そしてなぜそれが大事なのか、いっしょに見ていこう！{{< /tanerisu >}}

## ひとことで言うと

{{< summary >}}
超伝導量子コンピュータの操作をすべてマイクロ波（電子レンジや無線と同じ仲間の電波）で行い、周波数ごとに分けて1本の線を共有するしくみを提案しました。1本の線で4つのゲートを同時に動かす実験では、2量子ビットゲートでも誤りが増えないことを示しました。

- 1本の線を4つのゲートで分け合っても、誤りは専用線とほぼ同じだった
- 2量子ビットゲートを周波数で分けて同時に動かしたのは、超伝導量子プロセッサーで初めてだと著者たちは述べている
- 必要な制御ラインの本数を、1〜2桁減らせる見込みを示した
{{< /summary >}}

## なぜこの研究が必要？

まちがいを自分で直しながら計算できる「誤り耐性」量子コンピュータには、数百万個の物理量子ビットが必要になると考えられています。論文によると、現在の先端的な装置は量子ビット1個あたりおよそ3本の制御ラインを使っています。このまま規模を大きくすると、外から引きこむ線は100万本近くになってしまいます。

実は、結果を読み出すための線は、すでに周波数で分けて共有されています。たとえば論文が例に挙げた装置では、次のような本数の線が使われています。

つまり、線を増やしている主な原因は「ゲート操作」のほうなのです。

{{< ask >}}じゃあ、ゲート操作の線も周波数で分ければいいのでは？{{< /ask >}}

{{< tanerisu >}}そこが難しかったんだ。2つの量子ビットをつなぐゲートは、これまで主に一方向の電流をパッと流す「パルス」で動かしてきた。このパルスには周波数という目印がないから、周波数で分けられなかったんだよ。{{< /tanerisu >}}

{{< htmlfig "pulse" >}}

これまでの実験で2量子ビットゲートの線を減らすには、順番待ちで線を使い回す「時分割」しかありませんでした。時分割では、線は減っても同時に動かせるゲートの数が減ってしまいます。また、冷凍機の中に電子回路や光ファイバーの変換器を入れる方法も研究されていますが、それらの部品自体が熱を出すことが課題でした。

## 何をしたの？

{{< flow "ゲート操作をすべてマイクロ波に" "周波数ごとに通り道を分ける" "同時に動かすゲートをグループ分け" "1本の線で4つ同時に実験" "線の数と熱を見積もる" >}}

**ゲート操作をすべてマイクロ波に**：2量子ビットゲートも、決まった周波数で振動するマイクロ波で動かす方式（MP-CZゲート）にしました。これで、どのゲートにも周波数という「宛先」がつきます。

**周波数ごとに通り道を分ける**：いくつものゲートの信号を1つの波にまとめて送り、決まった周波数だけを通すフィルター（バンドパスフィルター）で、それぞれの量子ビットやカプラーへ振り分けます。

**同時に動かすゲートをグループ分け**：誤り訂正の計算では、同時に動くカプラーは一部だけです。同時に動くものは周波数で分け、動くタイミングがちがうグループどうしは同じ周波数を時分割で使い回します。

**1本の線で4つ同時に実験**：実際の超伝導量子プロセッサーで、1本の線から4つの1量子ビットゲート、4つの2量子ビットゲートをそれぞれ同時に動かし、誤りの大きさを測りました。

**線の数と熱を見積もる**：同じ並べ方をくり返して大きな装置にしたとき、線の本数と冷凍機に入る熱がどれだけ減るかを計算しました。

| 項目 | これまで | 今回 |
|------|-----------|------|
| 2量子ビットゲートの動かし方 | 一方向のパルス（周波数の目印なし） | マイクロ波（周波数で宛先を指定） |
| 2量子ビットゲートの線の共有 | 時分割のみ（同時に動かせる数が減る） | 周波数で分けて同時に動かせる |
| 線の分け方 | 基本は1つの対象に専用線 | 周波数分割と時分割を組み合わせる |

## しくみをもう少しくわしく

### マイクロ波で動かす2量子ビットゲート

この研究の2量子ビットゲートは、2つの量子ビットの間にあるカプラーを、マイクロ波で細かくゆらす方式です。ゆらす周波数は、2つの量子ビットの周波数の差などから決まります。この周波数がそのまま、フィルターで振り分けるときの「宛先」になります。

ただし、どんな周波数でもよいわけではありません。論文は理論とシミュレーションで、周波数の差が特定の値に近いと、量子ビットが別の状態にもれ出したり、カプラーが余計に励起されたりして誤りが増えることを示しました。それでも、うまく動く周波数の範囲は十分に残っていると述べています。

{{< tanerisu >}}ラジオの局どうしが近すぎると混信するように、周波数の選び方がカギなんだね。{{< /tanerisu >}}

### 周波数と時間を組み合わせる

誤り訂正の計算では、2量子ビットゲートは「この時刻はこのカプラーたち」というように、層に分かれて順番に実行されます。論文はこの性質を使い、同時に動くカプラーを同じグループにまとめました。グループの中は周波数で分けて同時に動かし、グループどうしは時間をずらして同じ周波数を使い回します。

{{< htmlfig "groups" >}}

### 混信をどこまで許せるか

フィルターが隣の周波数の信号を完全には消せないと、それが「混信」としてゲートに入りこみます。論文は、120ナノ秒のゲートにわざと別の周波数の信号を加えるシミュレーションで、その影響を調べました。

その結果、周波数の間隔を100MHz（メガヘルツ）にする場合、フィルターは100MHz離れた信号を50dB以上弱める必要があると見積もりました。また、ゲートの時間を長くして波形をなめらかにした理想的な条件の計算では、周波数の間隔30MHzを目安として使っています。

{{< htmlfig "spectrum" >}}

### 4つの条件で比べる実験

実験では、フィルターや信号の分け方が誤りにどう影響するかを切り分けるため、4つの条件を順番に比べました。

{{< htmlfig "conditions" >}}

1量子ビットゲートは長さ40ナノ秒、2量子ビットゲートは120ナノ秒（前後に4ナノ秒ずつ待ち時間）です。誤りは、ランダムな操作を重ねて正しさを調べる方法（XEB）で、時間をずらして5回ずつ測りました。

なお、フィルターは今回、冷凍機の外の常温部分に置かれています。条件をすばやく切りかえるためで、論文は、ゲートの比較で大事なのはフィルターの置き場所ではなく、信号の通り道の特性が安定して補正できることだと説明しています。

## 何がすごいの？

一番の成果は、1本の線を4つのゲートで分け合っても、誤りが目に見えて増えなかったことです。

2量子ビットゲートの誤り（XEBで測った値）は、専用線のときが(6.53±0.24)×10⁻³、1本の線で4つ同時に動かしたときが(6.43±0.16)×10⁻³でした。つまり、線を共有しても誤りはほぼ同じです。論文は、2量子ビットゲートを周波数で分けて同時に動かしたのは、超伝導量子プロセッサーでは初めてだと述べています。

1量子ビットゲートでは、フィルターを入れただけだと誤りが大きく増えました。しかし波形を補正すると(10.10±0.20)×10⁻⁴まで下がり、専用線の(10.38±0.35)×10⁻⁴と区別できない水準になりました。4つ同時に動かしても(10.57±0.23)×10⁻⁴で、統計的に意味のある悪化はなかったとしています。

線が減ると、冷凍機に入る熱も減ります。論文は、RSA暗号（2048ビット）を解ける規模の約38万1000個の量子ビットを想定し、制御ラインから冷凍機の最も冷たい段に入る熱を見積もりました。専用線なら約400マイクロワット、12分の1なら約33マイクロワット、48分の1なら約8.3マイクロワットです。下の図で、減らし方と熱の関係を確かめられます。

{{< htmlfig "heat" >}}

希釈冷凍機の最も冷たい段の冷却能力は5〜30マイクロワット程度とされています。48分の1まで減らせれば、制御ラインからの熱はこの範囲に収まる計算です。ただしこれは線そのものから伝わる熱だけの見積もりで、フィルターやスイッチなどの部品から出る熱は含まれていません。

## まだできないこと・課題

- **実験はまだ「1本で4つ」まで**  
  量子プロセッサーの大きさと、信号をつくる装置が出せる周波数の幅に限りがあったため、実証は1本の線で4つまでにとどまっています。

- **48分の1は理想的な条件での見積もり**  
  ゲートの時間を長くする、フィルターが波形をゆがめないなど、いくつもの仮定を置いた数字です。論文自身、量子ビットの寿命が有限であること、フィルターの性能、周波数のずれ、補正の手間などにより、実際の比率はこれより下がると述べています。

- **マイクロ波の2量子ビットゲートは時間が長い**  
  一方向のパルスで動かすゲートに比べて時間がかかるため、そのぶん量子ビットの状態がくずれる影響を受けやすくなります。量子ビットの設計や製造が進めば、この弱点は小さくなると期待されています。

- **冷凍機の中への組みこみはこれから**  
  今回フィルターは常温部分に置かれていました。実用化には、フィルターや電圧源を冷凍機の中に組みこみ、周波数の割り当てや量子ビットごとのばらつきへの対策も必要です。

{{< tanerisu mood="puzzled" >}}「誤りが増えない」ことは分かったけど、何百・何千のゲートを本当に束ねられるかは、まだこれからなんだね。{{< /tanerisu >}}

## これからどうなる？

論文は、今回の周波数分割に、チップ上で電圧をつくる回路と、冷凍機の中で信号の行き先を切りかえるスイッチを組み合わせる構想を示しています。これらをまとめて実装（パッケージング）すれば、低温部分に置く制御の一式ができると考えられています。また著者たちは、この方式によって、これまで現実的でなかった数の制御ラインを、今ある希釈冷凍機の能力の範囲に収められる見通しが立ったと述べています。

一般に、量子コンピュータの大規模化は、量子ビットの性能だけでなく、配線や冷却といった「裏方」の技術にも左右されます。もしこうした配線を減らす技術が実用化されれば、1台の冷凍機に入れられる量子ビットの数が増え、誤り訂正を本格的に使った計算に一歩近づくかもしれません。

{{< tanerisu mood="happy" >}}目立たない「配線」の工夫が、未来の量子コンピュータを支えるかもしれない。こういう研究にも注目してみてね！{{< /tanerisu >}}

## 用語ミニ辞典

{{< term name="周波数分割多重（FDM）" >}}1本の線に、周波数のちがう複数の信号をまとめて流す技術です。ラジオで局ごとに周波数が分かれているのと同じ考え方です。{{< /term >}}

{{< term name="時分割多重（TDM）" >}}1本の線を、時間をずらして順番に使い回す技術です。線は減らせますが、同時に動かせるものの数は減ります。{{< /term >}}

{{< term name="バンドパスフィルター" >}}決まった範囲の周波数の信号だけを通し、それ以外を弱める部品です。今回は、まとめて送った信号をそれぞれの宛先へ振り分ける役目をしています。{{< /term >}}

{{< term name="CZゲート" >}}2つの量子ビットの両方が「1」のときだけ、状態に特別な印（位相）をつける操作です。量子ビットどうしを結びつける計算に欠かせません。{{< /term >}}

{{< term name="希釈冷凍機" >}}超伝導量子コンピュータを、絶対零度に近い極低温まで冷やす装置です。最も冷たい部分で取り除ける熱はごくわずかなので、入りこむ熱を減らすことが大切です。{{< /term >}}
