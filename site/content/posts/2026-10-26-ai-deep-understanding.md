AIに難しい概念を質問して、返ってきた説明を読んでも「なんとなく分かった気はするけど、説明はできない」と感じたことはありませんか。

私（LK）も、ChatGPTを使い始めたころはそうでした。説明そのものは正しそうなのに、頭の中で具体的なイメージが浮かばない。読み進めるうちに知らない単語が増えて、最後には何の話だったのか分からなくなる。

いろいろ試すうちに、AIの説明が驚くほど分かりやすくなる2つのコツにたどり着きました。この記事では、その2つを具体的なプロンプト付きで紹介します。

## コツ1：「アニメーションを見ているかのように細部まで詳細に説明してください」と頼む

深く理解したい概念があるときは、質問の最後にこの一文を付け足します。

```
〇〇について、アニメーションを見ているかのように細部まで詳細に説明してください。
```

### なぜ分かりやすくなるのか

教科書や普通の説明は、「〇〇とは△△である」という**定義**や**結果**から入ることが多いです。ところが、理系の概念の多くは「何が起きて、次に何が起きて、その結果どうなるか」という**過程**を理解できたときに、はじめて腑に落ちます。

「アニメーションのように」と頼むと、AIは時間の流れに沿って、場面を1コマずつ追うように説明してくれます。

- 最初にどんな状態なのか
- 何がきっかけで、どこがどう動くのか
- その結果、最後にどうなるのか

という順番がはっきりするので、頭の中で映像として再生できるようになります。一度映像として理解できると、定義の文章も「あの場面のことを言っているんだ」と結びつくようになります。

### 使い方の例

理系の科目なら、どの分野でも使えます。

```
電磁誘導で電流が流れる仕組みについて、アニメーションを見ているかのように細部まで詳細に説明してください。
```

```
SN2反応が進む様子について、分子の動きをアニメーションを見ているかのように細部まで詳細に説明してください。
```

```
神経細胞で活動電位が伝わっていく過程について、アニメーションを見ているかのように細部まで詳細に説明してください。
```

```
フーリエ変換が何をしているのかについて、アニメーションを見ているかのように細部まで詳細に説明してください。
```

### さらに分かりやすくするアレンジ

それでも難しいと感じたら、次のように付け足すと効果的です。

- 「**スローモーションで、1コマずつ**説明してください」…変化が速すぎて追えない部分を細かく分けてくれます
- 「**最初に登場人物（登場する物質や物理量）を紹介してから**説明してください」…何が動いているのかを先に把握できます
- 「**途中で私に質問を投げかけながら**説明してください」…受け身で読むだけにならず、自分で考えながら理解できます

## コツ2：ポスターセッションを1対1で聞く感覚で、わからない単語はすぐ別タブで聞く

専門的な内容を質問するときは、学会のポスターセッションで、発表者に1対1で話を聞いているような感覚で向き合うようにしています。

ポスターセッションは、研究内容をまとめたポスターの前で、発表者から直接説明を聞ける発表形式です。大人数の講演と違って、分からないところがあればその場で「それはどういう意味ですか？」と聞けるのが特徴です。

AIとのやりとりも、これと同じように使えます。

### 読んでいる途中でも、すぐ別のタブを開いて聞く

AIの説明を読んでいて、

- 新しい、知らない単語が出てきた
- 前の文とのつながりが分からなくなった

というときは、**読んでいる途中でも、その場ですぐに別のタブを開いて**AIに聞きます。

ポイントは「後でまとめて調べよう」と思わないことです。わからない単語を1つ残したまま読み進めると、その単語を前提にした次の説明も分からなくなり、わからない部分が雪だるま式に増えていきます。最後まで読んだのに結局わからない、という状態の多くは、途中のどこかで置いてきた1つの単語が原因です。

その場で解消してから元のタブに戻れば、説明の流れを見失わずに最後まで理解しながら読み進められます。

### 別のタブで聞くときのプロンプト

別のタブで聞くときは、**どんな文脈で出てきた言葉なのか**を一緒に伝えると、的外れな説明になりにくくなります。

```
「（元の説明の分野や話題）」の説明を読んでいて、「（わからない単語）」という言葉が出てきました。
この文脈での意味を、大学1年生にもわかるように簡単に教えてください。
```

例えば次のように使います。

```
「熱力学第二法則」の説明を読んでいて、「準静的過程」という言葉が出てきました。
この文脈での意味を、大学1年生にもわかるように簡単に教えてください。
```

### 別のタブにする理由

同じ会話の中で聞いても構いませんが、私は別のタブで聞くようにしています。

- 元の会話は本題の説明だけが続くので、あとから読み返しても流れが追いやすい
- 寄り道の質問を気軽に何度でもできる
- 寄り道先で分からない言葉がさらに出てきても、また別のタブで聞ける

本を読みながら辞書を引くのと同じ感覚で、メインの説明と寄り道の質問を分けておくと、頭の中も整理されます。

## 2つのコツを組み合わせると、さらに深く理解できる

この2つは組み合わせて使うのがおすすめです。

1. まず、メインのタブで「アニメーションを見ているかのように細部まで詳細に説明してください」と頼む
2. 説明を読みながら、わからない単語や流れが出てきたら、すぐ別のタブで聞く
3. 理解できたら元のタブに戻って、続きを読む
4. 最後に、学んだ内容を自分の言葉でAIに説明してみて、「間違っているところがあれば指摘してください」と頼む

最後の手順4を入れると、自分が本当に理解できたかを確かめられます。人に説明できるかどうかは、理解度を確かめる一番確実な方法です。

## 注意点：AIの説明は必ず教科書や講義資料で確かめる

AIの説明はとても分かりやすい一方で、もっともらしい間違いが混ざることがあります。特に、数式や数値、細かい条件は間違えやすい部分です。

- 大事な定義や公式は、教科書や講義資料で確かめる
- 説明が教科書と食い違っていたら、「教科書では〇〇と書かれていますが、どちらが正しいですか？」とAIに聞き直す
- 課題やレポートに関わる使い方をするときは、授業や大学の生成AIの利用ルールを必ず確認する

AIは答えを写すための道具ではなく、自分で理解するための家庭教師のような存在として使うのが一番効果的だと感じています。

## まとめ

AIで専門的な内容を深く理解するための2つのコツを紹介しました。

- **コツ1：** 深く理解したいときは「アニメーションを見ているかのように細部まで詳細に説明してください」と頼む。過程が順を追って見えるので、頭の中で映像として理解できる
- **コツ2：** ポスターセッションを1対1で聞く感覚で、わからない単語や内容が出てきたら、読んでいる途中でもすぐ別のタブを開いて聞く。わからないまま読み進めて結局わからない、ということがなくなる

どちらも今日からすぐに試せる方法です。次に難しい概念にぶつかったときに、ぜひ使ってみてください。
